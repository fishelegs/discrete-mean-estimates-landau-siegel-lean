# Finite mathematical diagnostics

These scripts are supporting finite checks, not asymptotic proofs or Lean certificates. Their original bytes and output labels are retained for reproducibility; the first-sector label “REPORT section 8” means Section 8 of `02_short_sector.md` in this publication. They require Python 3 with the already available packages mpmath and sympy. No software installation is part of this checkpoint.

To rerun without changing tracked files, copy one sector's `checks.py` to a fresh temporary directory and run `PYTHONDONTWRITEBYTECODE=1 python3 checks.py` there. Compare its generated `CHECKS.json` with the corresponding `EXPECTED_CHECKS.json`. Floating-point details may vary with library versions; the checkpoint assembly replay records whether its own environment matched byte-for-byte.

The first-sector script checks rational exponent bookkeeping, local Euler majorants including ramification, shifted prime powers, finite convolution/Mellin masks, parity projectors, divisor covering and finite four-gamma contour examples. The second checks signed-real-part perturbations, mixed head/dual identities, finite sector partitioning, functional-equation scalars for both character parities and the Gaussian Mellin/CDF kernel, including its half-weight at the endpoint.

The proof obligations involving all moduli, arbitrarily large integration heights, and sufficiently large D are addressed in the mathematical notes, not certified by finite examples.

The smaller-inverse-tail script checks primitive character/Fourier identities, optimized hyperbola and positive convolution algebra, finite discarded/retained masks and exact norm/cross exponent budgets. It does not numerically instantiate the exceptional hypothesis. The four-branch script checks CRT root factors, all six character kernels and principal corrections, exact mask algebra, prime-power arithmetic and conductor/Dirichlet phase identities. It does not certify a weighted correlation sign, an energy lower bound or an asymptotic saving.

The smooth-balanced-diagonal script checks the exact cutoff-average transition algebra, constant-factor support reserves, infinite-shell exponent budgets, critical-line real parts, all-parity unit-modulus functional-equation scalars, full equality-row divisor contraction and square-root normalization including ramified conductors, weighted harmonic envelopes, restricted even-principal subtraction, and arbitrary common bounded tuple coefficient caps. Its finite cutoff averages use discrete probability measures to test the algebra; the fixed smooth profile's all-height Mellin decay and asymptotic row estimate are proved in [the mathematical note](../06_smooth_balanced_diagonal.md). The checkpoint assembly replay matched the original expected JSON byte-for-byte. No claim about an unknown balanced cross or the old bump-train weights follows from these tests.

The Gaussian-principal script checks two-sided hard cutoff differences, the global outer Gaussian convolution inequality, Gaussian-log Mellin inversion, artificial-conductor principal contour identities with p-Euler factors and combined zeta residues (including a repeated pole), nonprincipal root reduction before principal subtraction, p-unit mask factorization, exact total-minus-equality bookkeeping, and equality-row divisor contraction. The original script's `REPORT.md` label refers to [the Gaussian-principal note](../07_gaussian_principal_mean.md). Its branch and contour tests are representative finite checks; the all-height estimates and source-interface support substitutions are proved in that note. The replay retains the original script and expected output bytes. Principal corrections do not bound the remaining oscillatory kernels or full positive branch norms.
