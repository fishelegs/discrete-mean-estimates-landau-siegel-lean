# Status: independently accepted source-level representations

The [frozen dyadic report](reports/DYADIC_REPORT.md) and its [independent review](reviews/DYADIC_REVIEW.md) establish actual C1/T1 finite-window exact-gamma right-minus-left arithmetic representations with normalized error O(a^-1 L^-14); C1 right separately has O(a^-1 L^-200).

The separately accepted [fixed-log addendum](reports/FIXED_LOG_ADDENDUM.md) and [independent extension review](reviews/FIXED_LOG_REVIEW.md) widen the bounded coefficient supports to A in [P^.502,P^.504], B in [P^.499,P^.500], J in [P^.500,P^.504]. They use C1 cutoffs P^.9995/P^1.005 and T1 cutoff P^1.005 on both sides, with unchanged errors. The frozen dyadic supports and cutoffs remain a distinct result.

All conclusions retain the original source parameters, assumption L(1,chi)<L^-2022, actual zeros and weights, all primitive real chi, both parities, original J1, inherited gamma branch, and character unit restrictions. No requested final exponent is changed.

Arithmetic main terms, favorable signed gain, actual mu-normalization, a nondegenerate mu-Gram matrix, and any Lean theorem remain unproved. Fixed profile width and coefficient harmonic norms do not prove actual zero-measure norm bounds; chi-masked coefficient norms retain the factor phi(D)/D.

Four finite algebra suites pass without the paper. Source-file identity checking is optional and explicitly skipped unless an external --source input is supplied; a separate recorded run verified the original external TeX hash. The package verifies after relocation. These regressions supplement the written proofs; they do not certify the remaining claims.
