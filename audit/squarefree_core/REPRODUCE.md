# Reproduce this source package

From the repository root, run:

```sh
python3 audit/squarefree_core/verify_bundle.py --repo .
```

The verifier checks public file hashes, exact dependency source pins, original versus portable receipt fields, and reruns both independent implementations. The small complex Gauss regressions use tolerance 1e-10; every exponent and logarithmic budget is rational arithmetic. Finite examples are not assumed to satisfy (A) and do not replace the universal analytic proof.

Historical source hashes use neutral identifiers and are distinct from the curated public byte hashes. The source package depends on the previously accepted high-rho/sparse analytic constructions. It neither re-proves all these dependencies in Lean nor proves a signed complementary bound.
