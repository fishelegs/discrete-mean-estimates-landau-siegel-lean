# Reproduction and verification scope

Use the pinned Lean 4.30.0 toolchain and repository lake-manifest. Run `lake build`, then `lake env lean -j1 audit/CloudProposition26Axioms.lean`. The audit driver enumerates all declarations owned by the 33 new production/regression modules, includes private/generated declarations without namespace filtering, checks all 294 public declarations and standard-axiom subsets, and prints full public types plus direct proof-term references. Compare the exact 437 owner/name/axiom records and 33 owner counts with the published inventories, or run `python3 -B audit/proposition26/check_audit.py path/to/captured-audit.log`. Its successful marker is `OWNERSHIP_PASS 437 PUBLIC 294`.

Run the two generated-import checks, `tools/check_no_placeholders.py`, `tools/check_lean_structure.py`, and `tools/spec_audit.py --strict`. The strict heuristic deliberately remains exit 1: 444 reviewed candidates, including two new local-derived-bound flags documented in STRICT_REVIEW.json. Zero unresolved new flags does not mean the entire paper has been semantically verified.

All 32 new production modules and the 15-theorem expanded-regression module were independently rebuilt centrally before the auditor. The full project then passed 5742 jobs, 1939 source guards and 1488/1753 Spec/All imports. Central verification rehashed all 7365 identified imported source files before and after. It also independently checked the earlier 60519 identified object/sidecar/build-metadata components; these counts describe actual verification scope, not an OS/runtime closure. The recorded 9024-byte Lean executable fingerprint does not identify every runtime library.

The verification JSON records command outcomes, timestamps and source/log/hash summaries. Binary caches, private machine paths and third-party source copies are not part of this publication. Hashes of private manifests preserve provenance but are not substitutes for the reproducible source proof or auditor. No custom axiom, sorry, admit, native_decide or contradiction from not-(A) was introduced.
